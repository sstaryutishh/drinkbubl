# drinkbubl

Static product page for the drinkbubl Sparkling Water Maker. The site lives in `dist/` and needs no install or build step.

## Deploy to Vercel

Import this repository into Vercel and deploy from the repository root. `vercel.json` selects the **Other** framework preset and serves `dist/` as the output directory. The page, styles, script, and images are all in that folder.

The shopping bag works in the browser and saves its count locally. Checkout is not connected; the page labels itself as a demo storefront.
